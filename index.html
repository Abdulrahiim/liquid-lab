Liquid neuron (train_compare.py)
def ltc_cell(p, x, u, dt):
    tau = softplus(p['tau']) + 0.05
    g = softplus(p['g'])
    h = dt / UNFOLD        # real time between photos
    for _ in range(UNFOLD):
        f = g * sigmoid(x @ W + u * U + b)
        x = (x + h * f * A) / (1 + h * (1/tau + f))
    return x

Uses dt, the real seconds between photos.

LSTM (train_compare.py)
def lstm_cell(p, state, u, dt):
    hs, c = state
    z = u @ Wx + hs @ Wh + b
    i, fg, g, o = split(z, 4)
    c = sigmoid(fg) * c + sigmoid(i) * tanh(g)
    hs = sigmoid(o) * tanh(c)
    return (hs, c)       # dt is never used

Never uses dt. It only counts photos.
